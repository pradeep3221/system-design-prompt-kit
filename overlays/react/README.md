# React / Next.js Overlay

Technology overlay for React and Next.js frontend applications.

## Overlay Files

| Overlay | Extends Base Prompt | Description |
|---------|-------------------|-------------|
| SPA Design | `frontend-spa-design` | React Router, Next.js App Router |
| State Management | `frontend-state-management` | TanStack Query, Zustand, Jotai |
| Component Design | `frontend-component-design` | React patterns, Storybook |
| Testing | `testing-unit` | React Testing Library, Vitest |

## Stack Summary

| Concern | Recommended | Alternative |
|---------|-------------|-------------|
| Framework | Next.js 14+ (App Router) | Remix, Vite + React Router |
| Language | TypeScript 5+ | — |
| Styling | Tailwind CSS | CSS Modules, styled-components |
| Server State | TanStack Query | SWR |
| Client State | Zustand | Jotai, Redux Toolkit |
| Forms | React Hook Form + Zod | Formik + Yup |
| Components | Radix UI + Tailwind | shadcn/ui, Headless UI |
| Testing | Vitest + RTL | Jest + RTL |
| E2E | Playwright | Cypress |
| Storybook | Storybook 8 | — |

## Usage

> "Apply the React / Next.js overlay to the above design. Use Next.js 14 with App Router, TanStack Query, and Zustand."
