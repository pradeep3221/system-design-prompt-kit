# Angular Overlay

Technology overlay for Angular applications.

## Overlay Files

| Overlay | Extends Base Prompt | Description |
|---------|-------------------|-------------|
| SPA Design | `frontend-spa-design` | Angular Router, standalone components |
| State Management | `frontend-state-management` | NgRx, Signals, RxJS |
| Component Design | `frontend-component-design` | Angular component patterns |

## Stack Summary

| Concern | Recommended | Alternative |
|---------|-------------|-------------|
| Framework | Angular 17+ (standalone) | — |
| Language | TypeScript 5+ | — |
| Styling | Angular Material + Tailwind | PrimeNG |
| State (feature) | NgRx Component Store / Signals | — |
| State (global) | NgRx Store | NGXS, Elf |
| Forms | Reactive Forms + custom validators | Template-driven forms |
| HTTP | HttpClient + interceptors | — |
| Testing | Karma + Jasmine or Jest | Web Test Runner |
| E2E | Playwright | Cypress |

## Usage

> "Apply the Angular overlay to the above design. Use Angular 17 with standalone components, NgRx Signals, and Angular Material."
